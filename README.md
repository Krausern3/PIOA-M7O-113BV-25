# PIOA-M7O-113BV-25

Лабораторная работа по расширению небольшой СУБД файловым хранением и индексацией.

## Структура проекта

```text
src/
  db/
    backend/
      database.py       # общий API менеджера базы данных
      errors.py         # пользовательские исключения
      file_csv.py       # файловая БД с хранением в CSV
      file_json.py      # файловая БД с хранением в JSON
      memory.py         # in-memory реализация и совместимые обёртки
      storage.py        # общая логика файлового хранения
      table.py          # модель таблицы, CRUD и индексы
    __main__.py         # точка входа
    tyi.py              # консольный интерфейс
  tests/
    test_file_databases.py
    test_memory.py
```

## Реализованная функциональность

- in-memory менеджер базы данных;
- файловый менеджер базы данных с хранением в JSON;
- файловый менеджер базы данных с хранением в CSV;
- создание, чтение, обновление, удаление и сортировка записей;
- фильтрация по произвольному набору полей;
- настраиваемые индексы по одному или нескольким столбцам;
- перестроение индексов после вставки, обновления, удаления и сортировки;
- загрузка сохранённых таблиц между запусками программы;
- автоматические тесты для `memory`, `JSON`, `CSV` и сценариев с индексами.

## Варианты хранения

### In-memory

- хранит таблицы только во время работы программы;
- не записывает данные на диск;
- подходит для быстрых проверок и временной работы.

### База JSON

- хранит каждую таблицу в `data/json/<table_name>.json`;
- сохраняет столбцы таблицы, индексируемые поля и записи;
- формат читается человеком и удобен для отладки.

### База CSV

- хранит каждую таблицу в `data/csv/<table_name>.csv`;
- сохраняет строку заголовка, строку метаданных индексов и все записи;
- закрывает дополнительное задание с альтернативным текстовым форматом.

## Индексация

Каждая таблица может поддерживать индексы по одному или нескольким полям. По умолчанию CLI предлагает индексировать все столбцы, но можно указать и произвольное подмножество при создании таблицы или позже.

Индексы используются при фильтрации, чтобы уменьшить число просматриваемых записей. После любой изменяющей операции таблица обновляет или перестраивает индексы, чтобы поиск оставался корректным.

## Запуск приложения

Из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m src.db
```

При запуске программа предлагает выбрать backend:

1. `In-memory`
2. `Файловая база (JSON)`
3. `Файловая база (CSV)`

