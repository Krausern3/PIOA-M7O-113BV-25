# PIOA-M7O-113BV-25

Лабораторная работа по переработке системы управления данными с использованием объектно-ориентированного подхода.

## Структура проекта

```text
src/
  db/
    backend/
      errors.py      # пользовательские исключения
      memory.py      # классы Table, DatabaseManager, StudentTable и совместимые обертки API
    __main__.py      # точка входа
    tyi.py           # консольный интерфейс на классах
  tests/
    test_memory.py   # тесты backend
```

## Реализованная функциональность

- хранение нескольких таблиц в памяти через класс `DatabaseManager`;
- работа с отдельной таблицей через класс `Table`;
- добавление, чтение, обновление и удаление записей;
- фильтрация записей по произвольному набору полей;
- сортировка записей по выбранному полю по возрастанию и убыванию;
- консольный интерфейс, переписанный с использованием класса `DatabaseCLI`;
- отдельный класс `StudentTable` с валидацией возраста и уникальности `id`.

## Запуск приложения

Из корня проекта:

```powershell
.venv\Scripts\python.exe -m src.db
```
